### 📌 A note on how I work

I care more about understanding *why* a system is built a certain way than shipping the fastest possible hack. Whether it's refactoring a billing flow into an atomic transaction to kill a race condition, or adding a deterministic safety floor under an LLM's judgment so a real failure mode can't slip through silently — I default to root-causing, not patching.
